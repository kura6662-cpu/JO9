# Patch source records

These JSON files preserve the source edits, expected occurrence counts, patch IDs and hashes used during development. They are useful for studying individual changes. They are not a single reproducible build chain for the current snapshot. Later manual edits and superseding patches exist. Do not apply the whole folder blindly. See source/jack.qsp for the final implementation and docs/BUILD_AND_QA.md for baseline-specific checks.
