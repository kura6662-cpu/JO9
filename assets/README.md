# Selected mod assets

This directory contains the image and styling source retained in the development repository, not the complete release artwork or external image packs. css-2.4/base.css and mainScreen.css and assets/json/*.json were refreshed from the current working game. Other supplied image paths can reflect their original patch-era layout.

SNKmod is no longer a runtime prefix in the current game. For those retained image files, remove the SNKmod path segment when locating their current references. The current QSP and menu JSON are authoritative; do not install a whole old asset tree blindly. The resources/new directory also contains authoring inputs and older icon paths that require their current reference to be checked.

Image-only replacements are reusable when the target paths match. A newly added UI icon still needs the QSP/JSON/CSS that uses it. Keep component credits and notices. This snapshot does not include all backgrounds/CG or any external pack.
